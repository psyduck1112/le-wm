train.py 需要的格式：

  train.py 通过 dataset[idx] 获取每个样本，期望返回：

  {
      "pixels": Tensor(T, 3, H, W),   # T 帧图片，已转为 CHW
      "action": Tensor(T, frameskip × action_dim),  # frameskip=1 时就是 (T, 7)
      "proprio": Tensor(T, 8),
  }

  其中 T = num_steps = history_size + num_preds = 3 + 1 = 4

  还需要额外实现两个方法供 train.py 调用：
  dataset.get_dim("action")      # → 7
  dataset.get_col_data("action") # → shape (52042, 7) 的 numpy array，用于计算归一化

转换方案：

  不需要生成新文件，在内存中完成转换：
  66个 parquet 文件
      ↓ pd.read_parquet 全部读入合并
  单个 DataFrame（52042行）
      ↓ 按 episode_index 分组，frame_index 排序
  428 个 episode 列表，每个是有序帧列表
      ↓ 滑动窗口，步长=1，窗口大小=4帧
  约 51000 个训练样本索引 (episode_idx, start_frame)
      ↓ __getitem__ 被调用时
  取出4帧 → JPEG解码 → 拼成 Tensor → 字段名映射 → 返回

  字段名映射：
  observation.images.image  →  pixels
  observation.state         →  proprio
  action                    →  action（不变）

  图片处理链：
  bytes(JPEG) → PIL.Image.open → np.array (256,256,3) → Tensor → permute → (3,256,256)
                                                           |  (train.py 的 transform)                                                 
                                                           ↓
                                                        resize → (3,224,224)
